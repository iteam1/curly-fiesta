# Curly Fiesta 🎉

## Quick Start

- To install dependencies: `uv sync` or `uv venv .venv && uv run pip install -e .`

- To install development dependencies: `uv sync --extra dev` or `uv venv .venv && uv run pip install -e .[dev,docs]`

- To view documentation: `uv run mkdocs serve`

- To run test suite: `uv run pytest`
